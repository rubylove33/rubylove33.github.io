What's new.

A short note for every Walk Habit release, newest first.

1.1.3 LatestMay 17, 2026

Highlights of this update

  • A short Walk Clip video — 2 seconds at the start and finish stitched into one — saves to Photos so you can share that day's walk with friends or on social media. (iPhone & Android)
  • Active walk progress appears on the Lock Screen and notifications: iPhone Dynamic Island (iOS 16.1+) and Android notification (with a status bar progress chip on Android 16+). Pause, resume, or end your walk straight from the notification.
  • Switch freely between selfie (front) and back camera when taking photos — capture scenery, objects, or yourself however the moment fits.
  • Every template and unlimited GIF creation is free, regardless of support. The in-app purchase is reframed as a voluntary way to support the solo developer.
  • Reporting a problem is one tap — Settings > Report a Problem, or any recent error entry, auto-attaches diagnostic info. If no mail app is available, the app shows a fallback message instead of erroring.
  • A recovery prompt lets you save an interrupted timer session or a pending Walk Clip start cut. iCloud backup keeps only the latest copy and restore is more reliable.
  • A weekly date selector and expandable Recent Sessions on Home make reviewing/editing past records natural, and you can set a start time for manual records. Album photo deletion and other flow details were polished as well.
  • Refreshed copy tone and overall design feel. Broad Android stability across Photos saving, email reporting, ad display, alarm permissions, and data migration.
1.1.1April 15, 2026

Recovery stability and record flow updates

  • Added a recovery prompt so you can save an in-progress timer session after the app closes unexpectedly.
  • Fixed the session cleanup flow so the recovery prompt does not reappear after a timer has already been finished.
  • Added a Report a Problem action in Settings and improved the fallback flow so it no longer errors when no mail app is available.
  • Fixed streak calculations so rest days and manual records are counted correctly on the home screen.
  • Removed the Pacemaker every minute setting to match the current record flow.
1.1.0March 28, 2026

Better record management and stability

  • Added a weekly date selector on the home screen to view and edit past sessions.
  • You can now set a start time when adding a manual record.
  • Fixed a bug where editing a session date did not actually change the date.
  • Added a delete button for selected photos in the album.
  • Cloud backup now keeps only the latest copy, with a clear restore hint.
  • Fixed iCloud backup restore always failing on real devices.
  • Backup/restore status messages now appear inside the sheet instead of behind it.
  • Fixed template icons not being visible after adding a photo.
  • Refined the record flow, guide copy, and overall color palette.
